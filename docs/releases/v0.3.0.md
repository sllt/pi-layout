# pi-layout v0.3.0

消费已发布的 `github.com/sllt/pi v0.3.0`，无本地 replace 要求。

- 一次性迁移命令提供 up/plan/status、target、dry-run、timeout 和 lock/TTL。
- up 默认加锁；plan/status 仅查看状态，可能初始化状态表。
- JSON 摘要写 stdout，诊断写 stderr；失败、锁冲突、超时、取消返回非零退出码。
- 移除旧 Fx migration hook；连接关闭后才报告命令成功，不启动 HTTP/gRPC/metrics 或数据库后台重连。
- 自带迁移改用 Name/UpContext，保留 SQLite 业务 DDL，其他方言必须先适配。

验收：公开 Pi module 消费，GOWORK=off 构建；命令、DI、server、middleware、errcode 的
定向 race；实际二进制 plan/up/status/重复/target/dry-run/失败/锁冲突/超时检查。
框架实库与兼容性说明见 [Pi v0.3.0](https://github.com/sllt/pi/releases/tag/v0.3.0)。

已移除的 `internal/server.RegisterMigrateServer` 属于脚手架内部入口；自定义启动代码应改为
调用 `internal/migrationcmd.Run(ctx, args, stdout, stderr)`。HTTP/task 继续使用现有 Fx 图。
锁无续租，命令 timeout 必须短于 TTL，用户迁移必须配合 context 取消。
